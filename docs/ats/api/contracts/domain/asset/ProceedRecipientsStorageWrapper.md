# ProceedRecipientsStorageWrapper

_Asset Tokenization Studio Team_

> ProceedRecipientsStorageWrapper

Library managing the proceed-recipient membership list and associated payload data.

_Membership is delegated to `ExternalListManagementStorageWrapper` keyed by `STORAGE_LOCATION_PROCEED_RECIPIENTS`; per-recipient bytes live at the dedicated `STORAGE_LOCATION_PROCEED_RECIPIENTS_DATA` slot._
