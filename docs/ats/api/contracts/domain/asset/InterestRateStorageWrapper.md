# InterestRateStorageWrapper

_Asset Tokenization Studio Team_

> InterestRateStorageWrapper

Library providing setters, getters, validation, and storage access for two interest rate models (fixed rate and KPI-linked) using deterministic storage slots.

_All functions are internal. Storage slots are accessed via inline assembly using precomputed position constants. The library is intended to be used by facet contracts that manage interest rate state._
