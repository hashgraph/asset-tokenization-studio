# SsiManagementStorageWrapper

_Asset Tokenization Studio Team_

> SsiManagementStorageWrapper

Internal accessor library for the SSI management ERC-7201 storage namespace.

_Centralises reads, writes, and presence checks against the issuer set and the revocation registry pointer. All helpers are `internal` and operate on the ERC-7201 slot resolved by {ssiManagementStorage}._
