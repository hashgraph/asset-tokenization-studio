# ProtectedPartitionsStorageWrapper

_Asset Tokenization Studio Team_

> ProtectedPartitionsStorageWrapper

Library providing storage access and logic for protected partitions.

_Provides functions to initialise, set, query, and validate protected partition state, as well as EIP-712 signature verification for transfers, redeems, holds, and clearing operations. All storage is accessed via a fixed slot defined in `STORAGE_LOCATION_PROTECTED_PARTITIONS`._
